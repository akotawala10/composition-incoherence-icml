# Sample dumps

Cached `K=8` verbalized-probability marginals from the four-LLM mid-tier panel
on Paleka cliques. Used by `scripts/verify_disagreement_bound.py` to verify
the empirical Proposition 3.5 bound.

Each `combined_<provider_model>.npz` contains:
- `forecast__JCD`: locally-projected K-sample marginals (one row per clique)
- `clique_sizes`: per-clique m

Each `combined_<provider_model>.json` contains:
- `relations`: per-clique relation type

These are generated by the JCD-Forecasting evaluation pipeline; the snapshot
here is the one used to produce the per-component verification numbers in
Section 5.9 of the paper.
